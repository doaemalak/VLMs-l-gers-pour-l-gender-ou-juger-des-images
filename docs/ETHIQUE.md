# Réflexion éthique

Points à développer au cours du projet :

1. **Biais des légendes** : les légendes générées peuvent refléter des stéréotypes
   (genre, âge, origine) présents dans les données d'entraînement des VLM.
2. **Erreurs et éléments inventés** : un VLM peut décrire des objets absents de l'image.
3. **Confiance dans un juge automatique** (option B) : jusqu'où le jugement du VLM
   peut-il remplacer celui d'humains ? Quels risques s'il est utilisé sans contrôle ?
4. **Données** : respect des licences des images, absence de données personnelles sensibles.
5. **Impact environnemental** : la quantification réduit la mémoire et les ressources nécessaires.
